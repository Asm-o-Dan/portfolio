О себе и подходе к разработке

Сфокусирован на надежности, чистой архитектуре и практической пользе решений для бизнеса.

Чистая архитектура и CQRS

Изолирую бизнес-логику внутри Domain Layer от деталей реализации баз данных и внешних фреймворков. Применяю CQRS для явного разделения операций записи (через EF Core) и быстрого чтения (через Dapper).

Асинхронность и фоновые процессы

Проектирую устойчивые планировщики сбора данных на Quartz.NET и BackgroundService с повторными попытками при сбоях и логированием. Использую RabbitMQ для развязки сервисов.

Командный рабочий процесс

Практический опыт работы в команде по Agile/Scrum в DEX Technology: строгое ветвление по GitFlow в GitLab, культура содержательных коммитов, покрытие логики тестами xUnit и участие в Code Review.
