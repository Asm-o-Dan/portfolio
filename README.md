## 🚀 Ключевые возможности & UX Инновации

1. **Perspective Switcher (Разделение по сценариям пользователей)**:
   - ⚡ **Overview (HR Fast-Track Bento Grid)**: компактный дашборд скрининга за 15 секунд (статус, стек, ключевые разработки, скачивание резюме).
   - 🔬 **Systems Lab (Split-View Explorer)**: интерактивная среда для тимлидов и архитекторов с кликабельными схемами слоев (*Domain ➔ Application CQRS ➔ Infrastructure ➔ Qdrant Vector Engine*), разбором инвариантов и кейс-стади.
   - 📄 **Dossier & CV**: строгое чистое резюме с таймлайном опыта, матрицей навыков и поддержкой печати (`@media print` + экспорт в PDF).

2. **Quake-Style Global CLI Terminal (Консоль по кнопке или `~` / `ESC`)**:
   - Эмулятор системного терминала `dan@asm-o-dan: ~ (bash / kernel v3.0)`.
   - Виртуальная файловая система (`ls`, `cat bio.md`, `cat stack.json`, `cat manifest.txt`).
   - Навигация по истории команд (стрелки вверх/вниз).
   - 🎮 **Пасхалка**: встроенный текстовый ретро-движок `tanks` с управлением танком и стрельбой прямо в терминале.

3. **Тактильный Dark-Tech Дизайн**:
   - High-contrast темная палитра (`#080c14`, cyan glow, emerald indicators).
   - Поддержка переключения темной и светлой темы с сохранением в `localStorage`.
   - Моментальная загрузка без сторонних тяжелых фреймворков (Zero-Dependency Vanilla JS).
